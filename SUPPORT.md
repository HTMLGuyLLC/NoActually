# Getting help

- **Questions and ideas:** [GitHub Discussions](https://github.com/HTMLGuyLLC/NoActually/discussions)
- **Bugs:** [open an issue](https://github.com/HTMLGuyLLC/NoActually/issues/new/choose) with your OS, app version and the steps to reproduce
- **A message counted wrong, or a catch that was missed:** use the "Wrong catch" issue form. Redact the text first, because issues are public.
- **Support for another AI tool:** use the feature form and pick "New AI tool support"
- **Security problems:** report privately, as described in [SECURITY.md](SECURITY.md)

Logs help with most bugs. They're in the app's log folder (macOS: `~/Library/Logs/app.noactually/`) and never contain chat text.
